## 🌅 關於我們

晨曦手作麵包坊創立於2015年，是由一群熱愛麵包的工匠所成立。我們秉持著對麵包工藝的熱情與追求，致力於為顧客提供最優質的手工麵包體驗。

### 我們的理念
- 🌾 堅持使用最天然的食材
- 🚫 拒絕添加人工色素和防腐劑
- 👨‍🍳 每一個麵包都經過工匠細心照料
- 🎯 只為呈現最完美的作品

## 🍞 產品特色

### 經典麵包系列
- **法國長棍** - 酥脆外皮，柔軟內心，搭配早餐或晚餐皆宜
- **全麥核桃麵包** - 使用100%全麥麵粉，添加核桃，健康美味
- **巧克力可頌** - 層層酥皮包裹著濃郁巧克力，每一口都是滿足
- **藍莓乳酪貝果** - Q彈口感，內含新鮮藍莓與香濃乳酪
- **天然酵母麵包** - 使用自家培養的天然酵母，口感綿密，香氣十足
- **肉桂捲** - 濃郁的肉桂香與甜蜜的糖霜，令人難以抗拒

## 🎓 烘焙工作坊

我們開設了專業烘焙工作坊課程，將麵包製作的樂趣與技巧分享給每一位喜愛麵包的朋友。

### 課程內容

#### 法式麵包工作坊
學習製作正宗的法國長棍、可頌和布里歐修等經典法式麵包，掌握揉麵、發酵和塑形的專業技巧。

#### 天然酵母工作坊
探索天然酵母的奧秘，學習培養和維護自己的天然酵母，製作出健康美味的天然酵母麵包。

#### 甜點麵包工作坊
學習製作各種美味的甜點麵包，包括肉桂捲、巧克力麵包、水果丹麥酥等，並掌握基礎的糖霜和巧克力裝飾技巧。
